# shawn-phy.github.io

The portfolio of Philip Shawn Oyuga, built with [Astro](https://astro.build), [Three.js](https://threejs.org) and [GSAP](https://gsap.com).

## Run it locally

Requires Node 22 or later.

```bash
npm install
npm run dev
```

The site runs at http://127.0.0.1:4321. `npm run build` writes the static site to `dist/`.

## Edit the content

Most text comes from `src/data/site.ts`: features, the three layers and their entries, flagship projects, roles, awards and contact links. The publishing rules (which facts may appear) are in `PRODUCT.md`.

The About section is yours to write, in `src/content/about.md`. While its frontmatter says `draft: true`, the section shows only on your local preview and is left out of the live site. Set `draft: false` to publish it.

## How the page moves

- `src/scripts/scene.ts` draws the three clay characters in one fixed WebGL canvas. They stand in the hero, come apart into an exploded view as you scroll, drop into their own sections and regroup at the end. Each character lands on the element marked `data-slot-for` or `data-crew` in its section.
- `src/scripts/app.ts` sets up smooth scrolling (Lenis), pins the hero on wide screens, and settles the halftone seams between sections.
- `src/scripts/text-fx.ts` runs the heading effects: power-on, decrypt, generate and wave, plus the date flips.

Under reduced motion none of this runs; the page shows the drawn stand-ins and rests.

## Illustrations

The figures and fallback characters in `src/assets/illustrations/` were generated by Philip from the prompts in `design/illustration-prompts.md`. Each image has a `.prompt.txt` sidecar recording how it was made. A slot with no image falls back to a drawn SVG stand-in.

To replace an image, save the new one under the same slot name. If you replace a project figure, re-measure its numbered callouts: each callout's `anchor` in `src/data/site.ts` points at a part of that specific image.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages. In the repository settings, under Pages, set the source to **GitHub Actions** once.
